swag

scale-wise adaptive gating for rotary position embeddings

rope hands every token the same fixed bank of positional frequency channels. swag lets each query token emit a gate per channel that scales only that channel's positional correction: which scales of "how far apart are we" this token cares about. the geometry itself never moves, so attention still depends on relative offset alone, exactly like rope. gates at 1 recover rope; gates at 0 ignore position; the whole thing computes exactly as one inner product in a doubled head dimension.

score = q·k  +  λh Σi gi(xm) ( qiᵀR((n−m)θi)ki − qiᵀki )

the learned gates, live

sixteen rope channels, fast on the left, slow on the right, spinning at their true rates θi = 10000−i/16. drag horizontally to scrub the relative offset. each dial's weight is the mean learned gate for that channel, measured from the trained model on 81,920 validation bytes. pick a token class and a layer. digits mute the local channels in layer 0; layer 3 converges on one shared mid-band scale; by layer 5 whitespace has mostly stopped caring about position.

the finding is a trade, not a trophy. learning the frequencies extrapolates prose best and quietly breaks the ruler: exact-offset recall collapses past the training length. swag is the only variant that improves on rope (best in-distribution number, both seeds, smaller degradation at every longer context) while keeping rope's relative-position robustness to the last decimal. costs 1.29× rope's wall-clock unfused. the in-distribution margin is about the size of rope's seed spread, and the paper says so, in those words.
