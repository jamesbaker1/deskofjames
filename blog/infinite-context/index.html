Infinite Context

Why Your Future Chatbot Won’t Need a Memory Palace of Text

jul 5, 2025

The latency tax of “let me go look that up”

Today’s long-context language models cheat: when they need to remember something, they stash the raw text in an external database and reignite the whole model to reread it. Retrieval-augmented generation (RAG) works, but every lookup costs money, milliseconds, and carbon.

A blank-slate sidekick

What if the memory were a model instead of a database, and what if it started with zero prior knowledge? I explore a memory transformer that learns only from the agent’s own conversations. No BERT, no GPT warm-up, no textual round-trips.

How it works

  1. Zero-pretrained memory transformer watches the dialogue stream and distills it into a dense vector z.

  2. Latent KV injection splices z straight into the frozen reasoner’s key–value cache, either as a fake “memory token” or as an extra key/value per attention head.

  3. A tiny gating network decides how loudly the memory should speak; safety checks mute garbage latents.

  4. Online training with replay buffers + elastic weight consolidation keeps the blank slate from catastrophic forgetting.

Why you should care

Because latents are hundreds of times smaller than full text, inference becomes decisively faster and cheaper; because only dense vectors move around, the risk of accidentally leaking private strings plummets; and because the memory starts life with zero baked-in priors, we finally get a clean sandbox for measuring what pure online interaction can really teach a model.
